# Supabase Setup — Trust Growth Society Ledger

এই ডকুমেন্টে ধাপে ধাপে দেখানো হয়েছে কীভাবে অ্যাপটিকে Supabase-এর সাথে যুক্ত করবেন, যাতে
লগইন, ক্লাউড ডাটাবেস, এবং সব ডিভাইসে অটো-সিঙ্ক চালু হয়।

## ১. Supabase প্রজেক্ট তৈরি করুন

1. https://supabase.com এ যান → **Start your project** → আপনার ইমেইল/GitHub দিয়ে সাইন আপ করুন (এটি আপনাকে নিজে করতে হবে)।
2. নতুন **Organization** তৈরি করুন (যদি জিজ্ঞেস করে)।
3. **New project** ক্লিক করুন:
   - Name: `trust-growth-society` (বা যেকোনো নাম)
   - Database Password: একটি শক্তিশালী পাসওয়ার্ড দিন এবং **সংরক্ষণ করে রাখুন**
   - Region: আপনার কাছাকাছি একটি অঞ্চল বেছে নিন (যেমন Singapore)
   - Plan: **Free** যথেষ্ট শুরুর জন্য
4. প্রজেক্ট তৈরি হতে ১-২ মিনিট সময় লাগবে।

## ২. স্কিমা (টেবিল) তৈরি করুন

1. বাম পাশের মেনু থেকে **SQL Editor** এ যান।
2. **New query** ক্লিক করুন।
3. এই রিপোজিটরির `supabase/schema.sql` ফাইলের সম্পূর্ণ কনটেন্ট কপি করে পেস্ট করুন।
4. **Run** চাপুন। সফল হলে সব টেবিল, নিরাপত্তা নীতি (RLS), ও রিয়েলটাইম চালু হয়ে যাবে।

## ৩. Edge Function ডিপ্লয় করুন (অ্যাডমিন যেন সদস্যদের লগইন তৈরি করতে পারেন)

1. বাম মেনু থেকে **Edge Functions** এ যান → **Deploy a new function**।
2. নাম দিন ঠিক এভাবে: `admin-manage-login`
3. এই রিপোজিটরির `supabase/functions/admin-manage-login/index.ts` ফাইলের সম্পূর্ণ কোড কপি করে পেস্ট করুন।
4. Deploy করুন। (SUPABASE_URL / SUPABASE_ANON_KEY / SUPABASE_SERVICE_ROLE_KEY — এই তিনটি Supabase নিজে থেকেই ফাংশনে দিয়ে দেয়, আপনাকে আলাদা করে কিছু সেট করতে হবে না।)

## ৪. অ্যাপে Project URL ও Anon Key যুক্ত করুন

1. Supabase Dashboard-এ **Project Settings → API** এ যান।
2. **Project URL** এবং **anon / public key** কপি করুন (এই দুটি পাবলিক, এগুলো ব্রাউজারে থাকা নিরাপদ)।
3. আমাকে (Claude-কে) এই দুটি মান পাঠান, অথবা নিজে `.env.local` ফাইলে বসিয়ে দিন:

   ```
   VITE_SUPABASE_URL="https://xxxxxxxx.supabase.co"
   VITE_SUPABASE_ANON_KEY="ey..."
   ```

## ৫. প্রথম অ্যাডমিন অ্যাকাউন্ট তৈরি করুন (Bootstrap)

যেহেতু প্রথমে কোনো অ্যাডমিনই থাকে না (কেউ থাকলে তবেই নতুন লগইন তৈরি করা যায়), প্রথম অ্যাডমিন
ড্যাশবোর্ড থেকে সরাসরি তৈরি করতে হবে:

1. আপনার মোবাইল নম্বরকে ইমেইলে রূপান্তর করুন এই নিয়মে:
   `01712345678` → `m01712345678@tgsbd.org`
   (শুধু শুরুর `0` সহ ১১ ডিজিট রাখুন, `m` দিয়ে শুরু করে `@tgsbd.org` জুড়ে দিন)
2. Supabase Dashboard-এ **Authentication → Users** এ যান → **Add user** → **Create new user**।
   - Email: উপরের ধাপে বানানো ইমেইল (যেমন `m01712345678@tgsbd.org`)
   - Password: আপনার পছন্দের পাসওয়ার্ড
   - "Auto Confirm User" চালু রাখুন
3. তৈরি হওয়ার পর ব্যবহারকারীর তালিকা থেকে তার **UUID** কপি করুন।
4. **SQL Editor** এ গিয়ে এই কুয়েরি চালান (UUID ও মোবাইল নম্বর বসিয়ে):

   ```sql
   insert into public.profiles (id, mobile, name, role)
   values ('PASTE-THE-UUID-HERE', '01712345678', 'আপনার নাম', 'admin');
   ```

5. এখন অ্যাপে গিয়ে সেই মোবাইল নম্বর ও পাসওয়ার্ড দিয়ে লগইন করুন — আপনি এখন অ্যাডমিন।
6. এরপর থেকে বাকি সব সদস্য/অ্যাডমিনের লগইন আপনি **Admin Panel → সদস্য লগইন তৈরি ও ব্যবস্থাপনা**
   থেকেই তৈরি করতে পারবেন — আর কোনো SQL লাগবে না।

## কীভাবে কাজ করে (সংক্ষেপে)

- সদস্যরা **মোবাইল নম্বর + পাসওয়ার্ড** দিয়ে লগইন করেন। পেছনে এটি একটি সিন্থেটিক ইমেইলে
  ম্যাপ হয় (`mobileToEmail`), কারণ Supabase Auth-এর ইমেইল দরকার হয় — এটি ব্যবহারকারীর
  কাছে সম্পূর্ণ অদৃশ্য।
- শুধুমাত্র **admin** রোলের ব্যবহারকারীরা অ্যাডমিন প্যানেল দেখতে ও ডাটা পরিবর্তন করতে পারবেন।
- সাধারণ **member** রোলের সদস্যরা সব তথ্য দেখতে পারবেন এবং ভোটিং-এ অংশ নিতে পারবেন — কিন্তু
  অন্য কোনো ডাটা পরিবর্তন করতে পারবেন না (এটি ডাটাবেস-লেভেলে RLS দিয়ে সুরক্ষিত, শুধু UI-তে
  লুকানো নয়)।
- ইন্টারনেট চালু থাকলে অ্যাপ স্বয়ংক্রিয়ভাবে Supabase-এর সাথে সিঙ্ক থাকে (Realtime) — একজনের
  পরিবর্তন সাথে সাথে অন্য সবার ফোনে চলে আসবে। ইন্টারনেট না থাকলে সর্বশেষ ডাটা লোকালি
  (localStorage) থেকে দেখা যাবে।

## এখনো যা করা বাকি (Known Limitations)

- সব "Add/Edit" বাটন এখনো UI-তে সবার জন্য দেখা যায়; বাস্তব সুরক্ষা ডাটাবেস RLS-এ আছে, তবে
  একজন সাধারণ সদস্য ভুলবশত কোনো "Add" বাটনে চাপলে সেভ ব্যর্থ হয়ে একটি টোস্ট মেসেজ দেখাবে।
  ভবিষ্যতে এই বাটনগুলো member-দের কাছ থেকে সম্পূর্ণ লুকিয়ে ফেলা যায়।
- বর্তমানে পুরনো `AdminCredentialGeneratorModal` (আইডি/পাসওয়ার্ড জেনারেটর) শুধু একটি
  প্রিন্ট-স্লিপ টুল — এটি বাস্তব লগইনের সাথে যুক্ত নয়। বাস্তব লগইন তৈরি করতে
  **"সদস্য লগইন তৈরি ও ব্যবস্থাপনা"** টুলটি ব্যবহার করুন।
- অফলাইনে থাকা অবস্থায় করা পরিবর্তন এখনো একটি queue-তে জমা থেকে পরে auto-sync হয় না —
  শুধু ইন্টারনেট থাকা অবস্থায় করা পরিবর্তনই সিঙ্ক হয়।
